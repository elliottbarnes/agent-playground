# Agent Guidelines

These instructions apply to this directory and everything below it.

- Keep each exercise small and focused.
- Before editing, read the relevant files and preserve unrelated work.
- After editing, review `git status` and `git diff` and run any relevant checks.
- For documentation-only changes, proofread the rendered result or plain-text structure.
- Do not add a remote, publish changes, alter Git identity, or change global Git settings unless explicitly asked.
- Never add secrets, credentials, or important personal files.
